# 分层排障

| 现象 | 先确认 | 处理与复测 |
| --- | --- | --- |
| 下载源失败 | 官网元数据可用，版本/哈希/大小齐全 | 用同版本且哈希一致的官网备用源；完整下载重新校验 |
| 签名或 Gatekeeper 不通过 | 下载 SHA256、实际 `.app` 路径、校验原始输出 | 停止安装，记录问题；不运行卸载/修复脚本，不关闭系统验证 |
| 管理端不可用 | 安装路径、客户端是否运行、端口是否被占用 | 启动准确应用；不杀占用端口的未知程序；`doctor` 复测 |
| 管理端在线但未登录 | `doctor` 的 `login_status` | `logged_out` 时在客户端登录；没有账号才引导邮箱注册；登录错误不擅自另注册 |
| 无法确认当前账号 | `login_status: unknown`、客户端版本、网络和实际界面 | 旧版可升级后重新诊断；网络恢复后再查询，不沿用旧用户名或凭列表成功推断登录 |
| 已确认登录但环境列表失败 | 当前用户名、账号访问权限、网络、套餐 | 核对目标账号并处理实际错误，再运行 `list`；不重复注册 |
| 新用户没有账号 | 用户邮箱和现有注册界面 | 引导获取邮箱验证码，在收件箱或垃圾邮件查收；用户完成密码设置和协议确认，注册后登录 |
| 邮箱验证码未收到或失效 | 邮箱拼写、垃圾邮件、页面发送提示 | 按页面提示重新获取并使用最新一封；仅辅助填写用户提供的验证码，不读取邮箱或保存验证码 |
| 注册提示邮箱已注册 | 当前邮箱和页面提示 | 回登录或找回密码，不重复注册 |
| 新建超时 | 精确名称是否已出现，客户端提示 | 先查列表，回执不明不重复创建；记录返回的真实ID |
| 环境无法启动 | 登录/额度、内核是否下载、磁盘、代理配置 | 按客户端实际提示处理；不自动修改原有环境或切换账号 |
| 已打开但 Bridge 不在线 | `doctor`、准确环境的扩展、实际扩展版本与能力 | 等待连接，检查扩展；不反复关闭重开，必要时在该测试环境补装官方扩展 |
| Bridge 健康但认证失败 | 本机 Token 文件和运行服务是否一致 | 只核对存在性和权限，不打印 Token，不替换其他任务服务 |
| 同名环境多条 | 返回的准确ID和用户业务绑定 | 明确目标ID，禁止取第一个或模糊命中 |
| 页面控制失败 | 精确browserId、tabId、当前快照、iframe和扩展能力 | 更新快照后有限重试只读步骤；核对页面最终状态，勿重复提交 |
| 关闭可能强杀 | 用户是否要求正常退出 | 正常退出浏览器；未允许客户端强制兜底时不调用 close API |

记录每个问题的触发条件、实际错误、影响、处理、复测结果。邮箱验证码可由用户填写或提供给 Agent 仅用于当前注册；不要将其误作图形 CAPTCHA 而停止辅助填码。图形 CAPTCHA 和账号安全验证由用户完成；有具体阻塞时保留当前任务状态并说明继续条件。若必须改 Electron/后端/内核才能处理，报告为未完成项，不擅自扩大本轮范围。
