# EasyBR AI 任务指令库

[返回项目主页](../README.md) · [接入与排障](AI-QUICKSTART.md)

这些指令用于已经接入本机工具的 Agent。把“指定环境”“指定网址”“提供的资料”替换为你的实际任务；不需要把密码、Cookie、Token 或邮箱验证码写进提示词模板。

## 怎样把任务说清楚

一条可执行的指令通常包含：**做什么、用哪个环境和账号、输入资料、允许做到哪一步、用什么结果确认完成。**

```text
任务：完成我描述的网页工作。
环境与账号：使用我指定的 EasyBR 环境，执行前核对环境名称、ID 和当前网站账号。
输入资料：使用我提供的文字、网址和本地文件。
操作范围：执行本次明确授权的读取、填写、上传及提交。
结果：回读最终页面状态，给出来源链接、截图或实际文件位置；未完成部分单独列出。
异常：结果未知先查状态，不重复提交；必须由我完成的安全验证出现时再通知我。
```

## 1. 首次接入和安装检查

```text
帮我接入 EasyBR，先检查安装、客户端版本、登录、环境和 Bridge。Mac 上需要安装时读取 easybr-agent Skill 并从官网下载正式包；Windows 按官网下载流程安装。有账号就登录，没有账号引导我通过邮箱注册并接收验证码。完成后列出就绪项和实际阻塞，保留已有环境。
```

## 2. 创建环境并确认能操作网页

```text
在 EasyBR 中新建一个名为“业务测试-当前日期时间”的独立环境，保留现有环境。保存后记录准确 ID，启动并检查内置 WebBridge。打开一个我指定的测试网页，读取标题并截图。若创建或启动超时，先查询实际状态再决定下一步，不重复创建。
```

## 3. 一次搜索并进入官网

```text
使用我选定的 EasyBR 环境，确认 WebBridge 已连接。打开百度，搜索一次 easybr，等待结果并辨认官网域名 www.ebrower.com，再点击官网结果一次，回读最终网址和标题。按正常浏览流程执行，不循环搜索或反复点击；如果没有找到或需要验证，按实际情况报告。
```

## 4. 继续已登录的业务后台

```text
在指定 EasyBR 环境中打开我提供的后台网址，核对当前账号。检查待处理事项和页面中的错误提示，按优先顺序列出任务、状态和来源链接。保留登录状态及其他环境，不改变账号设置。
```

## 5. 按资料填写并保存草稿

```text
在指定环境和账号中，按我提供的资料填写目标表单，保存为草稿。回读每个关键字段，检查必填项和校验提示，再给出草稿链接或记录名称及预览截图。若保存超时，先检查草稿是否已经生成。
```

## 6. 上传文件并确认处理完成

```text
在指定环境的目标页面上传我提供的本地文件。核对文件与任务对象，按页面要求完成裁剪、封面或必要资料，等待网站显示上传及处理完成，再检查预览。最后报告文件名、目标记录和页面状态；没有处理完成时不要把“已选择文件”当作上传成功。
```

## 7. 下载报表或附件

```text
在指定环境和账号中，下载目标页面的指定日期范围报表或附件。核对日期与筛选条件，下载后检查本机实际文件，告诉我文件名、保存位置、大小和内容是否符合要求。若已有同名文件，先区分本次新下载，不覆盖未确认的旧资料。
```

## 8. 完成明确授权的发布或提交

```text
我授权你在指定 EasyBR 环境和网站账号中，将我提供的内容与附件提交到指定对象。按现有页面完成任务所需的检查、填写、上传及最终提交；提交前核对账号和内容，提交后回读记录及最终状态。不要重复询问每个按钮；出现对象不明确或必须由我完成的安全验证时再停止。
```

## 9. 读取网页资料并整理报告

```text
使用指定环境读取我提供的网页，整理与主题相关的内容。每条结论保留对应来源链接，区分页面事实和你的推断；相同信息去重，缺少数据时注明未找到。报告输出到本次任务文件夹，并提供简短摘要。
```

## 10. 多环境分别检查

```text
对我指定的几个 EasyBR 环境依次检查同一项后台状态。每次先核对环境 ID 和网站账号，使用各自的任务标签组，不复制其他环境的登录资料。结果按“环境、账号、状态、证据、问题”分别列出，发现账号不匹配时停止该环境的操作。
```

## 11. 页面检查、截图和 PDF

```text
在指定环境中检查我提供的页面流程，记录可见的布局问题、错误提示和无法完成的步骤。对每个问题给出页面地址、复现步骤、截图和实际影响。需要 PDF 时导出并检查文件；完成后保留最终结果页面，清理本次创建的临时标签。
```

## 12. 检查连接并从失败处恢复

```text
从本次任务失败的位置继续。先检查 EasyBR 管理端、登录、指定环境、Bridge、扩展和当前页面，保留原始错误。已经成功的创建、上传或提交先核对状态，不再次执行。修复涉及本次任务的设置后重测失败步骤，并区分已通过、仍失败和需要我处理的事项。
```

## 13. 整理成可重复运行的工作流

```text
把这次已完成的流程整理成可重复执行的任务说明：列出环境选择、输入资料、步骤、成功依据、超时后的状态查询和失败恢复。需要定时执行时使用我的 Agent 或已有任务调度器，先说明频率与运行条件；不要把单次手动运行写成已经配置了定时任务。
```

## 14. 找到正确的帮助教程

```text
根据我描述的 EasyBR 问题，先到官网帮助教程中查找对应文章，再结合当前客户端版本、错误信息和环境状态排查。使用相关的 API、WebBridge 或界面能力处理问题。说明引用了哪篇教程、实际做了什么和复测结果；文档没有的能力不要编造。
```

提示词描述的是任务目标，不保证任意网站都能完成所有步骤。网站权限、版本能力、安全验证或产品缺陷应按实际结果报告。资料更新：2026-10-23。
